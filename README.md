#
🤖 R2D2 — Building Our Own Astromech Droid

A La Bestia 3D Project

Welcome to our R2D2 project!

We’re building our own 3D-printed astromech droid, combining 3D printing, electronics, robotics and a healthy dose of experimentation.

This project is about more than building a robot. It’s about learning, experimenting, solving problems and sharing the journey.

Our goal is to document the entire process, from the first printed component to a fully operational droid.

🌐 Website: https://labestia3d.com

⸻

🚀 The Project

Our R2D2 is based on the excellent Build-A-Droid project created by Neebick, available on MakerWorld.

The original design uses the CyberBrick ecosystem and provides a fantastic starting point for building a functional astromech droid.

We’re building our own version using a Bambu Lab H2D 3D printer.

Along the way, we’ll explore improvements, modifications and additional features.

🛠️ Project Goals

* Build a fully assembled 3D-printed R2D2.
* Integrate electronics and motion control.
* Experiment with lighting and interactive features.
* Explore additional functionality and improvements.
* Document successes, failures and lessons learned.
* Share our experiences with other makers.
